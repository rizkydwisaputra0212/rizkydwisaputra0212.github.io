# Rizky Dwi Saputra — Portfolio v1

A static, responsive career portfolio made for free GitHub Pages hosting.

## Files
- index.html — all portfolio content
- style.css — design
- script.js — tiny JavaScript
- Rizky_Dwi_Saputra_CV_International_2026.pdf — optional CV download

## Publish for free
1. Create a PUBLIC GitHub repository named exactly `rizkydwisaputra0212.github.io`
2. Upload these files to the repository root.
3. Open Settings → Pages.
4. Source: Deploy from a branch → `main` → `/ (root)` → Save.
5. Open `https://rizkydwisaputra0212.github.io`

## Easy updates
You do not need to learn web programming. For normal text changes, open `index.html` on GitHub, click the pencil/Edit icon, change the text, then Commit changes. The website will update automatically.

## Add project images later
Create `assets/` and upload screenshots there. We can later add project galleries without changing the hosting.

Only publish screenshots, source code, diagrams, medical information or client information that you are authorized to disclose.
